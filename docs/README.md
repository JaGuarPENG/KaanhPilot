# 项目设计文档

这里保存 KaanhPilot 的持续设计记录。文档记录已经形成的共识和仍待确认的问题，不保存逐句聊天流水。

## 文档入口

- [项目发展计划](./PROJECT_PLAN.md)：项目目标、阶段、优先级、完成标准和待确认事项。
- [程序架构](./ARCHITECTURE.md)：程序分层、依赖方向、运行模式和适配边界。
- [当前代码地图](./CODEBASE_MAP.md)：当前入口、核心类依赖、实际调用链和结构缺口。
- [项目词汇表](./CONTEXT.md)：订单、机器人任务、Workflow、Command 等统一术语。

## 维护约定

1. 目标、优先级或里程碑发生变化时，更新 `PROJECT_PLAN.md`。
2. 模块职责、调用方向或适配方式发生变化时，更新 `ARCHITECTURE.md`。
3. 一个项目术语的含义达成共识时，更新本目录 `CONTEXT.md`。
4. 未确认内容必须明确标记为“待确认”，不能写成既定事实。
5. 只有难以逆转、存在真实取舍且未来难以从代码理解的决定，才单独建立 ADR。
